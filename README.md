# <h1>🚀 JavaScript Mini Projects</h1>

A collection of **20 JavaScript Mini Projects** built using **HTML5, CSS3, and Vanilla JavaScript**. These projects cover fundamental to intermediate JavaScript concepts such as DOM Manipulation, Events, Local Storage, Fetch API, Async/Await, Debouncing, Throttling, and API Integration.

---

## 📌 Projects Included

| No. | Project | Description |
|-----|---------|-------------|
| 1 | Character Counter | Count characters while typing. |
| 2 | Date | Display current date and time using JavaScript Date object. |
| 3 | Form Validation | Validate user inputs before form submission. |
| 4 | Clipboard | Copy text to clipboard using Clipboard API. |
| 5 | Dark Mode | Toggle between light and dark themes. |
| 6 | Tabs | Switch between different content sections. |
| 7 | Modal Popup | Open and close modal popup windows. |
| 8 | Todo App | Add, delete, and store tasks using Local Storage. |
| 9 | Stopwatch | Start, stop, and reset a stopwatch. |
| 10 | Image Slider | Navigate through multiple images. |
| 11 | Debouncing | Optimize search input by delaying execution. |
| 12 | Throttling | Limit function execution during continuous events. |
| 13 | Drag and Drop | Implement drag-and-drop functionality. |
| 14 | Weather Search | Search and display weather information dynamically. |
| 15 | Meal API | Fetch and display meal data using TheMealDB API. |
| 16 | Meal Search | Search meals dynamically using API. |
| 17 | Random Meal | Display a random meal from API. |
| 18 | Single Meal | Show complete details of a selected meal. |
| 19 | Pagination | Display data page by page. |
| 20 | Infinite Scroll | Load more content automatically while scrolling. |

## 🚀 Getting Started

### Clone the Repository

```bash

```

### Open the Project

```bash
cd javascript-mini-projects
```

Open any project folder and run the **index.html** file in your browser.
